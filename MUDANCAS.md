# O que mudou em relação ao protótipo da E2

| O que mudou | Por quê |
| --- | --- |
| A fonte aparece logo abaixo do título da resposta, e o selo "Atual · 2 dias" abre a fonte | No teste, P3 confiou só no selo e não viu as fontes no rodapé |
| "Isso não responde minha dúvida" virou dois controles: "Buscar de novo" e "Enviar feedback sobre a resposta" | P3 não sabia se reiniciava a busca ou enviava feedback |
| Tela 4 tem dois botões lado a lado, com uma frase sobre quando usar cada um | P2 hesitou entre pedir acesso e trocar os termos |
| O editor está rotulado "editor de código (fora do protótipo)", com cursor padrão e aparência inativa | P2 clicou no editor achando que era interativo |
| A tela 3 mostra data, hora e autor da última edição | P2 queria confirmar que o README não mudou "ontem" |
| O aviso ficou "não use a página antiga da wiki" | P1 reagiu bem ao aviso; o texto ficou mais direto |
| "Abrir no original" está desativado | Não existe repositório real por trás da demonstração |
| Nome "UmaBusca", tema claro/escuro e menu recolhível no celular | O protótipo não tinha nome; o navegador exige adaptar a barra e a árvore de arquivos em telas pequenas |
| Quinta página "Sobre" (problema, princípio e grupo) | A E3 pede de 3 a 5 páginas; esta apresenta o contexto da E1 |
| Filtro e ordenação de fontes | Pedido da E3: interatividade com manipulação do DOM |
| Navegação real no topo, no lugar do botão "Facilitador" | No site, quem visita precisa navegar sem o facilitador |
| O selo "Atenção" usa o badge do Bootstrap | A E3 pede um componente com framework; o protótipo já usava um selo arredondado |
| Árvore de arquivos escondida abaixo de 768 px | Falta largura no celular |
